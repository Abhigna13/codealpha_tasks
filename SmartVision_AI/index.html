🤖 SmartVision AI

An AI-powered Object Detection Platform developed using Python, Streamlit, OpenCV, and YOLOv8.

Project Features

  • AI-Based Object Detection
  • Real-Time Webcam Detection
  • YOLOv8 Deep Learning Model
  • Confidence Score Prediction
  • Object Count Analysis
  • Detection History and Analytics Dashboard

Technologies Used

Python | Streamlit | OpenCV | YOLOv8 | Pandas | PyTorch
